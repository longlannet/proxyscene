# proxyscene v0.12.1

修复订阅更新后旧节点残留和等价节点重复的问题。更新以该订阅本次返回的完整列表替换旧列表，并同步处理失效的节点选择。继续使用固定 Xray v26.9.9 和 Go 1.27.1，无新增依赖。

## 订阅更新

- 已撤回的订阅节点会删除，包括当前选中的节点；旧列表 10 个、新列表 15 个时，该订阅更新后对应 15 个节点（等价连接去重），不会累加成 25 个。手动节点及其他订阅仍提供的节点继续保留。
- 以完整连接配置识别等价节点。仅备注、参数顺序或等价编码变化时复用已有节点 ID，更新托管节点的链接及提供方默认备注，保留自定义备注和有效测速结果。新链接与必须保留的手动/其他订阅节点重合时复用该节点，避免重复链接阻止保存。
- 被撤回节点的默认/场景选择优先迁移到等价节点，否则迁移到原订阅当前列表的首个节点。开启场景的实际连接变化时，通过既有事务校验并更新 Xray；重复更新或等价连接迁移无需重启。沿用已保存的监听地址、端口和服务用户，不应用本次环境中的无关运行参数。
- 下载或完整性校验失败时不提交新列表；运行配置更新或状态保存失败时执行事务回滚。清理撤回节点的测速记录，保留完整批次校验和并发状态变更拒绝。

## 旧节点迁移与升级

- 新增「订阅管理 → 关联旧节点到订阅」及 `subscription adopt <订阅序号或ID> <节点ID...>`。关联只登记归属，不立即删除节点或重启代理；后续更新按完整列表替换。
- 未记录来源的历史节点无法与独立手动节点可靠区分，因此继续保留并显示提示。确认归属后需显式关联一次；不要关联需要独立保留的手动节点。旧版本保留的无来源托管节点会在更新时清理。
- 升级后首次更新可能替换正在使用但已从订阅撤回的节点，并重启 Xray。更新不自动测速，替代节点取自订阅列表，不保证供应商节点当前可连接。
- 固定安装入口和默认自更新继续使用 dl.ll.cd。发布信任保持为受控 GitHub immutable Release 和镜像 HTTPS；SHA256 提供完整性校验，本版未引入独立发布者签名。需要降级时使用升级前整套备份，并按既有运行时恢复要求操作。

## 验证

增加完整列表替换、来源隔离、等价链接去重、选择迁移、真实服务替换及重复刷新检查；发布门禁包含特权订阅回归、重启与保存失败的事务回滚测试。修复节点检测测试读取 `/proc` 参数时的短暂空值竞争，保留隐私和降权断言。
