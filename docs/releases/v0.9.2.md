# proxyscene v0.9.2

修复 Hermes 系统安装使用 uv Python 目录符号链接时被拒绝、报 `not a directory` 的问题。解释器文件和目标路径中的可信目录链接均可识别，无需改动 Hermes 安装布局。

## 修复与安全边界

- 逐段通过文件描述符验证解释器路径；目录、链接与最终文件均须属于 root，目录和文件不可由组或其他用户写入。
- 拒绝不安全权限、非规范链接目标、循环、超过 16 个链接及非普通可执行文件；程序根目录、`venv/bin` 和配置文件的符号链接限制保留。
- 校验不执行已安装的 Python，也不导入 Hermes 模块。
- 正式发布默认包含 GitHub 和 dl.ll.cd：GitHub 完成检测、发布和发布后验证后，再同步镜像、逐字节验证全部资产并更新 Latest。任一处失败都不算完成发布。

## 升级前须知

本版修复解释器路径兼容性，不会自动修改 Hermes 的 Telegram 消息保留策略。运行中的网关仍要求最终有效的 `drop_pending_on_cold_boot` 为布尔值 `false`。

旧接管记录缺少用户身份或恢复依据时仍拒绝自动迁移；不要通过补填当前 UID/GID/home、删除 journal 或修改版本字段绕过检查。`tg on`、`install --skip-node`、`boot-restore` 是正式操作，可能写配置和协调服务，不能当作只读预检。

继续使用 **Go 1.27.1** 和固定 **Xray v26.9.9**（上游预发布版）。从较早版本升级请同时阅读 [v0.9.0](https://github.com/longlannet/proxyscene/releases/tag/v0.9.0) 和 [v0.9.1](https://github.com/longlannet/proxyscene/releases/tag/v0.9.1) 的兼容说明。

## 发布验证

发布门禁包括单测、race、静态和漏洞检查、root 权限测试、两次四架构构建逐字节比较，以及一次性 Debian 13/systemd 安装和升级测试。uv 回归覆盖可信目录链接、相对路径、属主和权限、循环及链接数量边界；真实 Python venv 服务夹具覆盖目录链接启动及不安全链接拒绝。

提供 Linux amd64、arm64、386、armv7 管理程序和离线 bundle，以及 `install.sh`、`checksums.txt`、`xray_source_v26.9.9.tar.gz`，共 11 项资产。完整性模型为 GitHub immutable Release 与 SHA256，不提供独立发布者签名。隔离服务夹具不等同于真实 Telegram 收发测试，发布也不代表已迁移使用者的本机配置。
