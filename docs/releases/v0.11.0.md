# proxyscene v0.11.0

新增固定镜像安装入口，并使默认检查更新及升级全程通过 dl.ll.cd 完成，目标机器无需访问 GitHub。发布端仍先完成 GitHub 检查、不可变发布和公开验证，再同步镜像。

## 安装与更新

- 固定入口 `https://dl.ll.cd/proxyscene/install.sh` 自动识别架构，锁定镜像已完成发布的稳定版本，也支持 `--version v0.11.0`。完整下载并校验 bundle 后调用包内原安装器。
- `proxyscene update --check`、默认 `update` 和菜单更新使用镜像的索引、版本元数据、校验清单和 bundle。显式 `--source github` 保留原 GitHub 直连方式；镜像失败不自动回退。
- 安装/更新限制固定来源、无重定向、文件大小和资产集合；校验 SHA256、内部 manifest 和程序身份，安装前复核固定版本。禁止自动降级及同版本 commit 冲突。
- 新安装使用安装锁内的不存在前态检查；已有程序替换继续使用原程序 SHA256 检查，防止下载期间另一进程安装或升级后被覆盖。

## 镜像发布

- GitHub Release 和镜像版本目录继续保留原 11 项资产。服务器另外发布不可覆盖的 `metadata/<tag>.json`，包含版本身份、更新说明及全部原资产大小/SHA256。
- 元数据由服务器从已验证的 GitHub Release 生成，公开校验成功后才提升 `latest.json`。固定引导脚本由 root 管理，镜像发布账号不能更改它。
- 客户端的信任来源明确为 dl.ll.cd 的 HTTPS、服务器和受控发布流程；SHA256 用于完整性验证，不是独立发布者签名。本版未引入签名密钥。

## 升级说明

固定入口支持本版及之后的版本。v0.10.0 的旧自更新仍要求访问 GitHub；可先使用新入口升级到本版，之后默认自更新无需 GitHub。旧版本的明确版本安装方式仍保留在 README。缺少系统工具时按提示准备依赖；不需要 Go 或 Node.js。

本版保持已有运行事务、身份和消息保留检查。安装器可能协调服务；旧异常状态仍需按提示核验或恢复，不能通过重新安装绕过。未修改 Xray v26.9.9 及 Go 1.27.1 固定依赖。
