# proxyscene v0.12.0

改进订阅兼容性和更新路径，补充五类节点协议能力，并把节点测速改为真实 HTTPS 代理转发检测。修复开发代理配置的属组保留问题，继续使用固定 Xray v26.9.9 和 Go 1.27.1。

## 订阅与协议

- 订阅更新先直连，不继承环境中的代理变量；下载失败时，仅通过已开启并保存的全局 HTTP 代理重试一次。保留目标 IP、重定向、大小和完整性检查，不会自动开启全局代理。代理回退仍需本地 DNS 正常解析。
- 兼容 `servername` 别名、TCP 的冗余 `mode=multi`、VMess/Shadowsocks 默认值以及可准确映射的 WS/HTTPUpgrade early data；等价字段冲突继续拒绝。解析失败显示脱敏原因，更新不完整时保留旧订阅节点。
- 支持 VLESS Encryption、Shadowsocks 2022 和 Hysteria2，包括 Hysteria2 跳端口、带宽、Salamander 及其组合。
- 支持 Clash/Mihomo YAML 的 `proxies`，以及 JSON 子集和 Base64 包装。仅导入节点，不执行规则、脚本或外取 provider；无法保持原意的字段明确拒绝。
- XHTTP extra 使用字段白名单和资源上限；与外层一致的冗余 host/path/mode 可以导入，冲突、未知字段和独立 downloadSettings 拒绝。

## 节点检测

- `node test` 和 `node auto` 通过每个节点实际请求 HTTPS，涵盖 Hysteria2；仅 TCP 端口可连接不会判为成功。自动选择使用本轮成功结果，并复核节点未被并发修改。
- 检测使用独立临时 Xray，以非 root 身份、空补充组、零 capabilities 和 NoNewPrivileges 运行；随机本地认证入口仅允许访问指定检测目标。
- 最多并发三个节点，批次总预算两分钟。检测取消或超时时不保存结果或切换节点，正常结束清理临时进程与文件；不会重启正在运行的代理服务。强制杀死管理器或主机崩溃仍可能留下私有的临时配置文件。

## 权限与升级

- 修改已有 Git/npm 配置时保留原 UID、GID 和权限，并检查并发元数据变更及中断恢复。新文件保持 0600；带显式 ACL 的已有配置安全拒绝修改，避免改变访问语义。
- 固定安装入口和默认自更新继续仅访问 dl.ll.cd，保留完整性检查、防降级与并发保护。正式发布门禁加入完整真实核心测试、特权节点检测、配置权限回归以及官方 v0.11.0 升级演练。
- 发布信任仍为受控 GitHub immutable Release 和镜像 HTTPS；SHA256 提供完整性校验，本版未引入独立发布者签名。

## 支持范围

支持 VLESS、VMess、Trojan、Shadowsocks 和 Hysteria2。TUIC、WireGuard、SSR、Hysteria v1、Shadowsocks 外部插件及 XHTTP downloadSettings 尚不支持，不会静默转换。真实协议测试使用可复现的本地服务端；订阅解析和配置校验通过不等于供应商节点当前可连接。
