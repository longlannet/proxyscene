# proxyscene v0.12.2

补齐删除全部节点的入口。节点管理菜单新增「8. 删除全部节点」，保留原有逐个删除功能。继续使用固定 Xray v26.9.9 和 Go 1.27.1，无新增依赖。

## 删除全部节点

- 菜单展示节点数量及受影响的场景，明确确认后才执行；直接回车、取消或输入结束均不删除。确认期间节点或配置发生变化时拒绝提交，避免误删新加入的节点。
- 支持 `proxyscene node remove --all`，`delete` 别名同样可用。命令行直接执行，不另行确认；拒绝多余参数，需要预览和确认时请使用菜单。
- 一次事务删除全部手动及订阅节点，清空默认节点、场景节点选择和测速记录，关闭全部代理场景并停用 Xray。清理已有场景接管记录；停止服务或保存状态失败时沿用既有事务回滚与恢复机制。
- 保留订阅地址，之后更新订阅可重新导入节点；不会自动恢复代理场景开关。节点列表已经为空时提示并返回。

## 验证与升级

增加菜单确认、取消、并发修改、参数校验、单次提交，以及三种场景清理和失败回滚测试；特权测试纳入 CI 和发布门禁。升级方式不变，可运行 `sudo proxyscene update`。

发布信任保持为 GitHub immutable Release 和镜像 HTTPS，SHA256 用于完整性校验；本版未引入独立发布者签名。
